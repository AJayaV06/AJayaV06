# 🎯 Featured Projects

## Speech Background Noise Suppression — MathWorks × Break Through Tech
Developed a deep learning pipeline to reduce background noise in speech recordings using spectrograms, improving audio quality while preserving speech clarity.

Highlights
- Researched audio representations and selected spectrograms for model training
- Trained an 856K-parameter GRU denoiser, improving PESQ by 0.216 across 172 test segments
- Built a reproducible preprocessing, training, and evaluation pipeline
- Plan to implement a Complex U-Net as the final model to enhance both speech magnitude and phase

**Tech**
Python • PyTorch • NumPy • Librosa • SciPy

➡️ **Repository:** [link](https://github.com/Break-Through-Tech/MathWorks-2A-speech-background-noise-suppression-with-deep-learning)
